# SG90 4축 로봇팔 — Arduino + PCA9685 구동 테스트

오픈소스 Mini Snapper(9g 서보용) STL을 직접 출력·조립한 4축 로봇팔을 아두이노 우노와 PCA9685로 구동 확인한 기록.
이후 Raspberry Pi5 + ROS2 연동 예정.

## 구성
```
노트북 --USB--> Arduino Uno --I2C(A4 SDA, A5 SCL)--> PCA9685 --PWM--> SG90 x4
                                                        ^
                                       AA 2구 홀더 2개 직렬(약 6V) → V+ / GND
```
- PCA9685 VCC ← Uno 5V (로직 전원), 서보 전원은 배터리에서만 공급
- 공통 접지는 PCA9685 보드 위에서 연결됨

## 코드
| 폴더 | 내용 |
|---|---|
| `01_i2c_scan` | I2C 스캔 — PCA9685 주소 0x40 확인 (0x70은 All Call 주소) |
| `02_channel_check` | 채널 확인 — CH0~15를 하나씩 움직여 관절별 채널 매핑 |
| `03_angle_limits` | 최대·최소 각도 설정 — 시리얼 입력 각도로 1°씩 천천히 이동 |

필요 라이브러리: Adafruit PWM Servo Driver Library

## 결과 (2026-11-01)
| 채널 | 관절 | 가동 범위 | 비고 |
|---|---|---|---|
| CH15 | 그리퍼 | 100(닫힘) ~ 150(열림) | 정상 |
| CH13 | 손목 | 5 ~ 110 | 정상, 숫자 ↓ = 아래 |
| CH11 | 팔꿈치 | — | 이동 시 기어 갈림 소리, 측정 중단 |
| CH10 | 어깨 | — | 미측정 |

## 문제와 다음 단계
- 하부 두 관절(어깨, 팔꿈치)이 하중을 못 버티고 처지며 기어 갈림 발생 → SG90 토크 부족 추정
- 부품 STL 기반 질량·무게중심으로 관절별 중력 토크를 계산해 원인 확인 예정
